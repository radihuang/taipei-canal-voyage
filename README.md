# 台北運河漫遊｜Taipei Canal Voyage

一款以**紀念碑谷（Monument Valley）**柔和幾何美學打造的 3D 瀏覽器網頁遊戲。將台北市區主要幹道（市民大道、忠孝、仁愛、信義、中山、復興、敦化、光復）化為運河，開著你的橘色船隻在城市中划船交朋友！

## 特色功能
- **四種時段光影**：清晨、正午、夕陽、夜晚平滑切換，夜晚建築窗格與運河橋燈自動點亮。
- **三種尺寸橘色船隻**：
  - `1 人` 單人立槳 SUP（初始）
  - `5 人` 優雅帆船（累積 30 分解鎖）
  - `10 人` 海盜船（累積 80 分解鎖）
- **交友與搭便車機制**：靠近 AI 船友揮手交朋友累積分數；靠近帆船或海盜船可暫時收起自己的橘船，跳上對方甲板一起漂流看台北。
- **台北 12 個行政區**：7 × 7 個街廓、8 × 8 條運河。北投、士林、內湖、大同、中山、松山、萬華、中正、大安、信義、南港、文山依相對方位排列（不照實際比例），各區建築高度與配色不同，北投、文山公園較多。進入新的行政區會跳提示，小地圖以玩家為中心並標示區名。
- **真實樹種的行道樹**：樟樹、臺灣欒樹、小葉欖仁、白千層、楓香、阿勃勒、茄苳、苦楝、大王椰子九種。每條運河兩岸種的是該路段實際最多的樹種（見下方「行道樹資料來源」），畫面右上會顯示目前所在運河的行道樹。
- **街上的行人**：每個街廓都有行人沿著外圈步道散步，有的會穿過中央十字步道、停下來歇腳。
- **水上載客**：岸邊隨時有旅人舉手等船，頭上寫著想去的行政區或地標（台北 101、中正紀念堂、大安森林公園）。開帆船（載 4 人）或海盜船（載 9 人）靠近就會上船、站在甲板上；開到目的地旁的運河就送達加分，路程越遠分數越高。小地圖會把船上乘客的目的地框成橘色。
- **送達知識卡**：把乘客送到 10 個目的地之一（三個地標，加上萬華、北投、信義、中正、士林、大同、大安）時，右下角會跳出一張在地知識卡，附資料來源連結，14 秒後自動收起，也可以按 × 關掉。卡片標示本次遊玩已收集幾張。
- **視線穿透**：船開到高樓後面時，擋住視線的建築與樹會以網點半透明顯示，不會看不到自己的船。
- **跨裝置操控**：支援電腦鍵盤（WASD / 方向鍵 / Space / E）與手機觸控（虛擬搖桿 + 互動鈕 + 雙指縮放）。


## 行道樹資料來源
臺北市政府工務局公園路燈工程管理處「臺北市行道樹及公園樹木分布圖」開放資料（[data.taipei](https://data.taipei/dataset/detail?id=7a49d00c-a5ff-4a6b-be9e-aaa6dc1ff7e8)，行道樹資料 CSV，2026-11-26 版，共 90,104 棵）。
每條運河取該路段在這 9 種樹裡數量最多的一種，前兩名接近時兩種交錯種，對照表與棵數寫在 `js/config.js` 的 `ewCanals`／`nsCanals` 註解。注意：
- 仁愛運河兩種交錯：仁愛路大王椰子 1,097 棵、樟樹 1,044 棵。
- 敦化運河兩種交錯：敦化南路臺灣欒樹 921 棵、樟樹 822 棵（敦化北路以樟樹為主）。
- 阿勃勒在主要幹道上都不是最多數，所以用長興街（124 棵，該路第一）與堤頂大道。

## 知識卡內容來源與授權
卡片內容取材自 [Taiwan.md](https://taiwan.md/)（CC BY-SA 4.0），每一句都回到官方或機構的原始資料核對過（區公所、文化資產局、北投溫泉博物館、中正紀念堂、公園處、工務局、文化局出版品、台北 101 永續報告書），2026-11-26 核對。核對不到的說法一律不放，例如中正紀念堂「89 階」、大稻埕 1869 年首批茶葉的斤數（各來源寫 12 萬斤、21 萬斤、12 萬公斤，互相矛盾），以及 101「2004–2010 年世界最高」。
每張卡的出處連結寫在 `js/knowledgeCards.js`，遊戲畫面上也會顯示。依 CC BY-SA 4.0 的相同方式分享條款，`js/knowledgeCards.js` 的卡片文字同樣以 CC BY-SA 4.0 釋出；其餘程式碼不受影響。
內湖、松山、南港、文山、中山目前沒有卡片：Taiwan.md 沒有可對應的文章，或是找不到官方原始資料可以核對。

## 本地預覽
因為使用了原生 ES Modules，請透過本地靜態伺服器開啟（不要直接雙擊 `index.html`）：
```bash
# Python 3
python3 -m http.server 8000
# 接著瀏覽器打開 http://localhost:8000
```

## 部署到 GitHub + Vercel
1. 在 GitHub 建立新 Repository 並把這個資料夾內所有檔案 push 上去。
2. 前往 [Vercel](https://vercel.com/) → **Add New Project** → 匯入你的 GitHub Repo。
3. Framework Preset 選 **Other**（不需設定 Build Command，Output Directory 留空）。
4. 點擊 **Deploy**，數秒內即完成上線，手機與電腦皆可直接打開連結遊玩！

## 測試入口
網址加上 `?debug`（例如 `http://localhost:8000/?debug`）時，瀏覽器主控台可用 `window.__game` 直接加分、移動船隻，供自動化測試使用；一般網址不會開啟。

## 常見錯誤與處理
- **知識卡的出處連結打不開**：政府網站偶爾改版或暫時連不上（例如公園處頁面）。卡片內容不受影響；改版造成連結失效時，到 `js/knowledgeCards.js` 更新網址。
- **直接雙擊 `index.html` 畫面全白**：ES Modules 不能用 `file://` 開，請照「本地預覽」起伺服器。
- **`python3 -m http.server 8000` 出現 `Address already in use`**：8000 埠已被別的程式占用，換一個埠，例如 `python3 -m http.server 8001`，再開 `http://localhost:8001`。
- **改了程式但瀏覽器還是舊畫面**：按 Cmd+Shift+R（Windows：Ctrl+Shift+R）強制重新整理。
- **手機上很卡**：地圖有 49 個街廓，靜態物件已合併成每個街廓十幾個 draw call；若仍卡，可在 `js/config.js` 調低各區 `heights`，或在 `js/pedestrians.js` 減少每個街廓的行人數。
